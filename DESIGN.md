# Kita Tools — Design Direction (Material 3 / Material You)

Dial: ENERGY 2 / RHYTHM 2 / MOTION 2

## 1. Product Identity & Personality
- **Product**: Kita Tools — Precision web utilities, shape generators, and server calculators crafted for Minecraft voxel architects, builders, and administrators.
- **Personality**: Tactical, precise, purposeful, modern, and crafted.
- **Visual Style**: Authentic **Material 3 (Material You / M3)** with a Minecraft-appropriate tonal palette. High visual clarity, tonal surface elevation instead of noisy shadows, and comfortable touch targets.

## 3. Shape Scale (M3 Corner Radii)
- **Extra Small (4px)**: Micro tags, tooltips.
- **Small (8px)**: M3 Filter Chips, input fields, badge pills.
- **Medium (12px)**: Menus, small cards, assist buttons.
- **Large (16px)**: Standard tool cards, preview containers.
- **Extra Large (20px - 28px)**: Feature cards (20px-24px), Dialogs & Modals (28px).
- **Full (9999px)**: Filled & Tonal buttons, Top App Bar Search Bar, Nav pills.

---

## 4. Typography Scale (M3 + Technical Modernity)
- **Headlines / Display**: `Plus Jakarta Sans`, font-weight 700 / 800, tracking-tight.
- **Body / Labels**: `Inter`, system-ui, font-weight 400 / 500 / 600.
- **Code / Metrics / Escaped Text**: `JetBrains Mono`, monospace.
- **Icons**: `Material Symbols Outlined` (Google Fonts).

---

## 5. Dials & Liveliness
- **ENERGY: 2** (Balanced): Confident, crisp Minecraft tools portal without noisy cartoonish decorations.
- **RHYTHM: 2** (Consistent with purposeful breaks): Cohesive card catalog with dedicated flagship spotlight and clean filter bar.
- **MOTION: 2** (Smooth transitions): 150-200ms easing for modals, theme flips, hover elevations, and filter pill active indicators.
